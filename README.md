## Interactive upward reading

**[Open the animation](index.html)** (or use the GitHub Pages URL after publishing).

Rather than automatically playing, the reader descends to the roots and then
scrolls upward through *Among Sequoia Sempervirens*. Each line gently uncovers
as it is approached from below. The position of every line stays fixed.

The animation is contained entirely in `index.html` and needs no libraries.
It includes **Read all**, **Guided reading**, and **Start over** controls, plus
reduced-motion support.

### Share online

In GitHub: **Settings → Pages → Build and deployment → Deploy from a branch**,
select **main** and **/(root)**, then save. GitHub Pages typically publishes at:
`https://pentaideas.github.io/eng111_writing/` (verify the URL in Pages settings).

## Revision history

Use descriptive Git commits for each revision. Existing alternative arrangements
have separate files so neither is silently overwritten. See [revision notes](notes/revision-log.md).

Git commit dates mark the archiving process, not the dates of original composition.
